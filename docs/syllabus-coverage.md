## Selected technical references

- GSM procedures are represented as teaching flows. The mobility walkthrough uses one intra-BSC example. [3GPP TS 23.018](https://www.3gpp.org/ftp/Specs/archive/23_series/23.018/) · [3GPP TS 23.009](https://www.3gpp.org/ftp/Specs/archive/23_series/23.009/)
- The Mobile IP and IPv6 lessons distinguish base link configuration from mobility binding and tunneling. [RFC 4861](https://www.rfc-editor.org/rfc/rfc4861) · [RFC 4862](https://www.rfc-editor.org/rfc/rfc4862) · [RFC 6275](https://www.rfc-editor.org/rfc/rfc6275)
- The MANET lesson uses an AODV example with a break, a route error and renewed discovery. [RFC 3561](https://www.rfc-editor.org/rfc/rfc3561)
- The SIP and media lessons distinguish session signaling, negotiated media and reception reports. [RFC 3261](https://www.rfc-editor.org/rfc/rfc3261) · [RFC 3550](https://www.rfc-editor.org/rfc/rfc3550)
